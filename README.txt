AMAR JYOTI COACHING CENTRE — STATIC WEBSITE

Files
- index.html: page structure and Tailwind utility classes
- styles.css: custom theme, responsive layout and component styling
- script.js: mobile menu, enquiry-to-WhatsApp form and active navigation

Run locally
1. Open index.html in a browser, or use VS Code Live Server.
2. Internet access is required for Tailwind CDN, Google Fonts, Lucide icons and remote images.

Deploy
Upload index.html, styles.css and script.js together to the website's public_html / public folder.

Notes
- Existing logo and selected image assets are referenced from amarjyoticoachingcentre.com.
- The enquiry form opens WhatsApp with the entered details. It does not store submissions in a database.
- Verify the institute address and current batch details before publishing. The address shown is the one on the current contact page.
- No unsupported selection counts, success rates or testimonials have been invented.
